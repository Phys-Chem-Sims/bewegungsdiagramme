# Bewegungsdiagramme

Interaktive Simulation für den Physikunterricht: Einen Wagen ziehen oder mit Reglern (x₀, v₀, a) fahren
lassen und dabei live das x-t-, v-t- und a-t-Diagramm entstehen sehen.

- Eine einzige HTML-Datei, ohne Bibliotheken; lädt nichts nach, speichert nichts, kein Tracking.
- Läuft im Browser am Handy, Tablet und Beamer, auch offline (Datei herunterladen und öffnen).
- Voreinstellungen über die Adresse, z. B. `?modus=ziehen&bahn=20` oder `?x0=1&v0=2&a=-0.5`.

Quelle ist ein lokales Unterrichts-Repo; diese Kopie dient nur dem Hosting über GitHub Pages.
